如果说 blog-v3 让我重新搭好了博客的骨架，那么 [Retypeset](https://github.com/radishzzz/astro-theme-retypeset) 则提醒我：文字本身也值得被认真对待。它没有用大图堆叠首屏，而是把重心放在字体、行距、对齐和留白上，读起来像翻开一本安静的书。

## 为什么是衬线

中文网页长期依赖黑体，清晰、现代，但长时间阅读容易少了一点“翻页感”。衬线字体在笔画收尾处有细微的装饰，能让眼睛在行与行之间找到节奏。现在正文默认使用 `Georgia / Songti SC / Noto Serif SC` 的组合，点击文章标题右上角的按钮即可在现代排版与书页排版之间切换。

> 好的排版不是让读者注意到它，而是让读者忘记自己正在看屏幕。

## 细节清单

这次借鉴的具体做法：

- 中文段落两端对齐，配合 `text-wrap: pretty` 减少孤字
- 标题使用 `text-wrap: balance`，并支持悬停显示锚点
- 分隔线改用居中的 `*   *   *`
- 代码块增加行号和一键复制
- 正文中按 <kbd>Ctrl</kbd> + <kbd>K</kbd> 打开搜索

```css
.prose {
  text-wrap: pretty;
  line-height: 1.95;
}
```

| 项目 | 之前 | 现在 |
| --- | --- | --- |
| 正文字体 | 系统黑体 | 可切换衬线/黑体 |
| 代码复制 | 无 | 悬停显示按钮 |
| 图片查看 | 无 | 点击放大 |
| 文章列表 | 仅卡片 | 卡片/列表双视图 |

## 动效要克制

Retypeset 的视图过渡很优雅，但它同时提供了 `reduceMotion` 开关。我在这里也做了同样处理：系统开启“减少动态效果”时，页面切换、主题切换和图片放大都会退化为即时完成。<mark>动效是解释状态变化的，不是表演</mark>。

---

最后，仍然是那句话：内容是主角，界面应该安静地退到一边。
